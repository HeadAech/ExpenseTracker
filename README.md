# Wally

In-production iOS app to manage your expenses. It's featuring planning your monthly budget, categorizing expenses, gathering history and presenting data in charts form.
<br>
<br>
The app is localized in languages: Polish, English, Spanish.
<br>
It's planned to return to TestFlight soon and release on AppStore.
